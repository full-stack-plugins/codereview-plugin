# CodeReview 命名与品牌说明

> **文档说明**：冻结 CodeReview 的品牌、命名与产品边界。
>
> **版本**：V1.0.0
> **最后更新**：2026-10-24

## 1. 品牌定位

- 一句话定位：CodeReview（代码变更审查）是 Partme Guard 研发防护体系中的独立插件。
- 目标用户：需要在 Agent 协作中保留可核验工程结论的研发团队。
- 核心价值：把检查、证据和修复建议变成可重复执行的命令，而不是依赖对话记忆。

## 2. 命名规则

- 英文名：CodeReview
- 中文名：代码变更审查
- 命令名：ocr
- 仓库名：codereview-plugin
- 展示格式：CodeReview（代码变更审查）

## 3. 产品边界

是什么：

- 独立安装、独立版本、独立执行的研发防护插件。
- 通过命令、Hook 或技能输出结构化结论和证据。

不是什么：

- 不是 Partme Guard 总命令。
- 不替代其他 Guard 的专业判断。
- 没有真实执行证据时不得报告 PASS。
