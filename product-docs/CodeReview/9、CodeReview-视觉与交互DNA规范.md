# CodeReview 视觉与交互 DNA 规范

> **文档说明**：定义 CodeReview 的终端输出、错误提示和交互语气。
>
> **版本**：V1.0.0
> **最后更新**：2026-10-24

## 1. 输出风格

- 人类可读模式：简洁、可操作、先结论后证据。
- JSON 模式：稳定字段，不混入日志。
- 错误：说明原因、影响和下一步，不输出伪成功。

## 2. 状态语言

| 状态 | 表达 |
| :--- | :--- |
| allow | 通过，并注明证据 |
| deny | 阻断，并给出修复方向 |
| unverified | 无法验证，不称通过 |
| DESIGN_ONLY | 设计存在，运行时未实现 |
| PARTIAL | 只覆盖部分链路或输入 |

## 3. 颜色与图标

- 只在人类可读模式使用颜色。
- JSON 模式不输出 ANSI 控制字符。
- 不使用夸张的“完美”“已解决”措辞。

## 4. 交互原则

- 写操作支持 --dry-run / --yes。
- 失败保留原始错误和证据。
- 不自动提交、推送或修改用户代码。
