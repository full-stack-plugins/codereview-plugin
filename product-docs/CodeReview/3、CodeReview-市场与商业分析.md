# CodeReview 市场与商业分析

> **文档说明**：说明 CodeReview 的目标问题、用户与竞争边界。
>
> **版本**：V1.0.0
> **最后更新**：2026-10-24

## 1. 问题

Agent 能快速修改代码，但团队仍需要可核验的工程结论：

- 改动是否越过架构边界。
- 提交和分支是否符合团队规则。
- 规格、测试和代码是否一致。
- 检查结论是否来自真实执行，而不是模型自述。

## 2. 目标用户

- 使用 Codex、ZCode、Claude Code 等宿主的研发团队。
- 需要把 Agent 产出接入 CI、Hook 或发布流程的平台团队。
- 需要保留审计证据的受监管项目。

## 3. 竞品与差异

| 类型 | 典型做法 | CodeReview 的差异 |
| :--- | :--- | :--- |
| 通用 linter | 只报告文件问题 | 统一 decision、证据和退出码 |
| 代码审查服务 | 依赖远端模型 | 可本地执行，结论可回读 |
| 工作流平台 | 绑定单一宿主 | 独立 CLI 与 Hook，可组合 |

## 4. 商业假设

- 开源插件作为入口，团队级治理和 CI 集成作为增值方向。
- 当前阶段优先真实可用性，不承诺未实现能力。
